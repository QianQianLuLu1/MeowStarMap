## 二、启动与运行说明

- 环境：Windows x64、Node 24、Git Bash。若测试出现 git 子进程 `missing config key GIT_CONFIG_KEY_*` 假失败，先查 env（`GIT_CONFIG_COUNT` 等）、干净环境复跑甄别，不改代码。
- 六项验证（逐项记录退出码）：`npm install` → `npm run build` → `npm test` → `npm run typecheck` → `npm run e2e:smoke` → `npm run test:ci-linux`。
- e2e:smoke 需要含本批改动的打包产物 ⇒ smoke 前先 `npm run dist:win`（打包①）；提交与版本核验后再终版 `npm run dist:win`（打包②）。两次打包必要：pre-commit 钩子可能改写源码，终版产物必须对应已提交树。
- 打包缺省落 `release/`；若被外部文件锁阻断，复用既有机制：builder `--config.directories.output=release-pkg` + `MEOWSTARMAP_E2E_PACKAGED_DIR=release-pkg/win-unpacked` 跑 smoke。不杀进程，持锁证据交用户裁决。

## 三、错误处理与兜底策略（审查判据）

- 渲染层异步 effect 必须有 alive 门闩/generation 守卫；定时器/监听器与 cleanup 成对；轮询门控关闭时清零（`vi.getTimerCount()===0`）。
- catch 不得静默吞业务错误；固定翻译键降级须附注释。
- localStorage 读写 try/catch 降级会话态；纯函数对非法枚举返回「不命中」不抛错。
- 日志沿用既有 logger 分层，不新增 console.log。

## 九、审查结论（T2，C1–C8 逐项）

1. **chip 快照一致性 ✓**：Layout 快照 effect 依赖 `[currentView, refreshTick]`，桥缺失置 null（chip=unavailable 不伪造）；Connect 2s 轮询经 `onServerStatusChange` 回传，`pollAliveRef` 守卫在途响应；refreshTick 经 `key=connect-${refreshTick}` 重挂载 + 快照补拉双路覆盖。
2. **embedded 灵感面板 ✓**：挂载首拉经 `loadList` 的 generation 守卫（`listGenerationRef`）覆盖卸载后 setState；卸载 effect 作废全部在途代次；轮询门控 `visible && !bridgeMissing`，cleanup 齐全；独立页折叠行为由 `!embedded && !detailsRef.current?.open` 分支保持。
3. **微信入口码 localStorage ✓**：读（L676）/写（L725）/切换读写（L796-797）三处均 try/catch，异常降级会话态（有注释）。
4. **SyncStatusBar ✓**：`showError` 仍被 `exportDiagnostics`（L99）消费；恢复提示门控 `serverStatus && available!==false && !running`（仅确定停机）；重启失败固定翻译键有注释说明。
5. **CSS 耦合 ✓（登记风险）**：`margin:-20px` + `height:calc(100%+40px)` 与 AppShell.tsx:178 `p-5` 实测一致；设计契约测试钉住作用域与关键选择器但未钉该常量——按最小改动原则登记留观，不强改。唯一 `#fff` 例外（--sc-paper 纯白锚点）有注释，合规。
6. **跨目录 ?url 导入 ✓**：`npm run build` 与 `build:preview` 均 exit 0，`sync-console-brand-*.png` 与 `wechat-mini-entry-*.png` 实测产出；品牌图 onError 回退 camera 图标。
7. **i18n ✓**：26 新叶子（166→192）×12 语齐备，键集守卫同步，i18n:guard/i18n:check 全绿。
8. **e2e helpers ✓（补覆盖）**：`packagedAppDir()` 实现正确但无测试——新增 `e2e/__tests__/helpers-packaged-dir.test.ts` 钉住缺省/空串空白/相对/绝对四分支（5 用例，首跑即绿，属覆盖补齐非缺陷修复）。
