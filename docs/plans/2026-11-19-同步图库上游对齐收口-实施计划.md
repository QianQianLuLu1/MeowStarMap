## 四、错误处理与参数校验（沿用前序两计划口径，本轮零新增通道）

- 主进程业务错误一律 AppError 家族经 wrapHandler 转 IpcError；11 条外壳/控制台通道 `z.tuple([schema.optional().default({})])` 元组校验，非法 action ⇒ VALIDATION_ERROR 结构化 issues。
- journal 逐条形状校验 + profile 白名单（`^(Any|Domain|Private|Public)(,(Domain|Private|Public))*$`），任一非法整体拒绝 restore；buildApplyScript 二次白名单防注入。
- 非法端口（含 0）⇒ failed/reason；子进程分层超时（查询 60s / UAC 300s / maxBuffer 16MB，`src/main/app/shell/shell-exec.ts`）。
- UAC 拒绝以退出码 1223/0x800704C7 主判据；外层 `-PassThru` 透出内层 ExitCode；restore 失败绝不清 journal；热点 stop 归属门前置零脚本执行。
- 渲染层 IPC 失败保留上次成功观测值（useSyncOverview）；opt-in 关闭 ⇒ disabled 零子进程；能力缺席 ⇒ available:false/unavailable 如实呈现。
