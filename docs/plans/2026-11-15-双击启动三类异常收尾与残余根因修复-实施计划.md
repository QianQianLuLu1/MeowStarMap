## 一、三类现象归因与关联（当前时点结论）

| 现象           | 归因                                                                                                                                                                        | 状态                                                          |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |

| ② 无弹窗闪退   | GPU FATAL 首崩静默自愈重启（下次启动升档，首崩无弹窗为 Chromium 行为）；旧版 dialog 吞异常（已修）；杀软替换二进制 EFTYPE（有弹窗路径）                                     | 仅首崩静默残留，取证可查                                      |
| ③ 已有实例运行 | 三选项对话框为**设计内单实例保护**；异常触发：旧版僵尸持锁（已修）、3s < 2-5s 清理期（F4 已修 6s）、**锁竞争窗口（本轮修）**、失败实例污染 boot-ok.marker（本轮随 R1 消除） | R1 后仅剩 before-quit 2-5s 窗口（6s 重试已覆盖）              |
