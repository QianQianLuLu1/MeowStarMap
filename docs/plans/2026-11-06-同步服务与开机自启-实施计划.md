## 6. 参数校验（入参类型 / 必填 / 边界 / 非法值）

- `settings:set` 既有 zod（`:76-82`）：`z.tuple([z.string().min(1).max(128), z.unknown()])` — key **必填**、字符串、长度 1~128；value 任意但 `JSON.stringify` 后 ≤ 1MB（`:85-93`）。本次**不改**。
- `launchAtLogin` 新增内联校验：`typeof value !== 'boolean'` 一律拒绝。非法值矩阵：`'true'`、`1`、`null`、`undefined`、`{}`、`[]` 全部拒绝且不写库、不调系统 API。
- `nikkisync.autoStartSyncServer` 走通用白名单，IPC 层不做强类型校验；读取端 `settingsFrom.getBoolean` 把非布尔脏值收敛为 `false`（**fail-safe 方向：绝不误开服务**）。
- `settings:get` 默认参数：同步服务页 `false`、设置页 `true`；与各自默认行为一致。
- `app.setLoginItemSettings` 入参只传 `{ openAtLogin: boolean }`，不引入 `path` / `args` 等投机参数。
- 所有外部输入（渲染层设置、SQLite 历史值、Electron API）默认不可信，均走上述校验或默认值兜底。
