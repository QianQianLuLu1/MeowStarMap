## 0. 依赖声明

**无新增依赖。** 全部改动仅使用：

- Node 内置模块：`node:fs`（`rmSync`）、`node:process`（`exit` 事件）——launch-server 清理用；
- 现有 devDependencies：`vitest`（单测）、`tsx`（脚本运行）、`electron`（`ELECTRON_RUN_AS_NODE=1` 运行时）；
- `CHANGELOG-2.5.3.md` 仅移动路径（根目录 → `docs/`），内容不变（用户已确认）。

## 1. 启动与运行说明

- 常规验证：`npm run verify`（只读：typecheck + eslint + prettier --check + 相关单测）。
- 全量回归：`npm test`（vitest 全套件）、`npm run typecheck`、`npm run lint`。
- launch-server 实跑验证（better-sqlite3 为 Electron ABI，无法在 vitest/plain node 下加载）：

  ```bash
  ELECTRON_RUN_AS_NODE=1 npx electron --import tsx scripts/sync-e2e/launch-server.ts --port 27124
  # stdout 期望出现一行 WXNN_E2E_INFO {json}；SIGINT/SIGTERM 优雅退出（退出码 0）
  ```

- 打包：`npm run dist:win`（build → pre-dist-check → electron-builder NSIS → verify:dist），
  产物 `release/NikkiGallery-Setup-2.5.5.exe`。

## 2. 错误处理（总体策略）

- 每个子任务完成后立即运行其验收命令，失败即停、修复后重跑，不累积错误。
- pre-commit/pre-dist-check 失败时按输出标记（`[PRE-COMMIT]` / `[VERIFY]`）定位阶段。
- 若 Mimosa 闸门拦截提交（06-e2e-report §8 曾出现），按闸门要求执行安全扫描后重试。
- launch-server：启动失败统一 stderr + `process.exit(1)`；退出路径经 `process.on('exit')`
  尽力清理自建临时目录（强杀 `taskkill /F` 不触发，属记录在案的已知局限）。

## 3. 参数校验（本次新增/收敛的校验行为）

- `launch-args.parseArgs`：`--port` 必须为 0–65535 整数（NaN/负数/越界/小数 → 抛错）；
  未知参数一律抛错（防拼写错误静默回落默认值）；`--serve` 接受为 no-op（常驻即默认行为，
  兼容文档历史写法）；`--host/--pair-host/--data-dir` 缺值时回落默认（与现状一致）。
- `api-router` export 端点：现有白名单/校验逻辑不变；仅新增（a）捕获异常记 `logger.warn`
  （此前完全静默）；（b）DB sha256 比较前小写归一（正则本允许大写、digest 恒小写）。
- `jpeg-export`：ImageDescription 12000 码元截断后剥离尾部残缺 `\uXXXX` 转义片段。
