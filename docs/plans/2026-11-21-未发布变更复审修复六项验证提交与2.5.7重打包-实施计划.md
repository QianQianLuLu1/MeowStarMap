## 三、错误处理

- 六项验证任一失败：TDD 定位根因（先写可复现红灯测试），修复后重跑；禁止跳过/弱化断言。
- 打包三闸门（`check-changelog-release` / `check-doc-versions` / `pre-dist-check`）失败即阻断：按报错修正源面，不改闸门脚本。
- 提交钩子（lint-staged + tsc -b + commitlint）拦截：修正信息/格式后重提，不绕过钩子。
- 暂存面防护：只显式 `git add` 实际变更文件，禁止 `git add -A`（防行尾噪声入库）；暂存后 `git diff --cached --stat` 复核。
- 打包 EBUSY：按仓库先例排查持锁进程。
