2. **`dist:win` 第 1 轮失败（TLS）**：electron-builder 下载 Electron 运行时 zip 报 `unable to get local issuer certificate`（GitHub 直连被网络环境阻断；本机未按 .npmrc 约定设置 `ELECTRON_MIRROR` 用户级环境变量）。**处置**：本次运行临时注入国内镜像（`https://npmmirror.com/mirrors/electron/`），不改仓库与用户配置。
3. **`dist:win` 第 2 轮失败（verify:dist 拦截）**：`@nikkisync 已建链但未随包`——第 1 步 `npm install` 将 `link:nikkisync` 的 junction 收敛为空 scope 目录（`10ec5ca` 代码注释明确记载的已知行为），electron-builder 在链接缺席态打包。**处置**：按闸门指引 `npm run link:nikkisync`（4 条链接重建）→ `verify:nikkisync` → 第 3 轮 `dist:win` 全链 exit 0，asar 扫描确认 @nikkisync 随包。此为产物闸门按设计工作（拦截缺运行时安装包），非缺陷。
4. **首轮全量 7 个 unhandled FileHandle GC 警告**（`scan-diagnose.test.ts` 驱动真实扫描链路，exifr 文件读取器句柄靠 GC 关闭）：GC 时序非确定性噪音（同代码库前轮全绿记录 exit 0），复跑未复现、不影响退出码。**留观不修**：根因在第三方 exifr 的 node fileReader，规避需改为整文件读入内存（大图内存代价更高）或 patch 依赖，均违背最小改动与复用优先；记录在此供后续如复现致败时按此口径处置。
