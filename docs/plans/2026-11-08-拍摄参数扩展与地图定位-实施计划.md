## 1. 背景与目标

MeowStarMap 已具备完整解密链路（`nuan5_decryption.dll` + koffi，主进程按需解密），但解密产物的利用停留在 V1 相机参数与基础 photo_info 字段。上游 nikki_albums 自 v3.012 起提供四类能力，本计划用本项目自身技术栈（Electron 41 + React 19 + TS strict + Zustand + Leaflet）对标实现，并合规接入其热更参考数据与 CDN 图片：

| #   | 能力                             | 上游首次引入 | 相关后续修复（已并入基线）                                    |
| --- | -------------------------------- | ------------ | ------------------------------------------------------------- |
| 1   | 拍摄地点展示 + 地图定位          | v3.012       | v3.012.02 热更哈希校验                                        |
| 2   | 拍照模式 / 风向 / 风力           | v3.012       | —                                                             |
| 3   | 双人合照对方动作参数             | v3.012       | v3.012.01 修复多人照片无法解析                                |
| 4   | 暖暖动作及进度、大喵动作及进度   | v3.012       | v3.012.01 修复灯光/滤镜/暖暖动作/大喵动作乱序、暖暖动作加分类 |
| 5   | CDN 图片资源合规接入（独立阶段） | v3.012       | v3.012.02 热更哈希校验 + 自动重下                             |

**不在范围内**：上游未合并的重构分支；相机参数编辑/导入（上游 parameter_manager）；单文件预览版；替换任何二进制；现有图片热链（gongeo.us 既有链路）的任何行为变更。

## 2. 授权与合规基线（实现必须逐条满足）

来自 nikki_albums#20 作者回复（2026-11-07）：

1. 解密思路与数据结构：可按 MIT 合规复用，须保留 MIT 版权声明并对上游署名。
2. 其参考数据（nuan5_database 中 `Nuan5NetworkImage`）指向的 CDN 图片：请求头须带 `User-Agent: MeowStarMap/<版本号>`（作者给的格式示例 `MeowStarMap/2.5.6`）。
3. 本地缓存 + 合理过期（作者示例 7 天），避免重复拉取。
4. 禁止绕过缓存高频请求；禁止对 CDN 资源二次分发或镜像；缓存/校验逻辑不得异常高频重试。
5. **cloth 与 cloth_outfit 相关 CDN 图片不在其可授权范围内**——归 gongeo.us 作者（dastrokes）授权。
6. 官方「奇迹大陆大地图」瓦片链接不要求 User-Agent；若上游自建 CDN 瓦片需另行授权，未同意前不默认接入。
7. 涉及新资源类型或请求方式建议先在 Issue 沟通。

来自 gongeo.us#218（dastrokes，2026-11-04）：已批准热链 `cdn.gongeo.us` 图片，要求携带可识别 User-Agent（本仓既有约定：固定串 `MeowStarMap`，见 `src/main/app/cdn-user-agent.ts`，**维持现状不改**）；建议自建面向大陆的加速节点（对应已定决策：设置页提供用户自配镜像入口，应用不代建节点）。

**落地动作清单**：署名进设置页「关于」区与分发物声明；`MeowStarMap/<version>` UA 仅作用于参考数据派生 CDN host（泛化 `cdn-user-agent.ts` 为 host→UA 映射）；图片全部走本地磁盘缓存（LRU + 7 天过期 + 404 负缓存）；不打包任何上游热更数据/CDN 素材进安装包；cloth/cloth_outfit 图标走 cdn.gongeo.us 既有已批准路径；建议在 #20 跟帖补充说明 v1.db 下载与本地解密的实现方式（"新资源类型先沟通"的稳妥动作，由仓库所有者执行）。

## 3. 上游技术事实（数据契约，均自上游 MIT 源码核实）

### 3.1 解密产物层（photo 参数）

解密 JSON 顶层（NikkiPhoto 类相册）关键字段（键名大小写变体在解析层做多形式兜底，沿用本仓 `pick` 惯例）：

| 顶层键                                          | 结构                                                                                                              | 本项目现状         |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ------------------ |
| `social_photo` → `photo_info`                   | PhotoInfo（相机/地点/动作位段）                                                                                   | 已解析（部分）     |
| `social_photo` → `track_info`（"TrackInfo"）    | `{ world_id }`（"WorldID"）                                                                                       | **未解析**         |
| `social_photo` → `da_miao_info`（"DaMiaoInfo"） | `{ cloth_ids: "ClothIDS", action: "Action", loc/scale/rot }`                                                      | 仅 momoHidden 布尔 |
| `normal_photo_info`（"NormalPhotoInfo"）        | `{ photo_mode: "PhotoMode", wind_intensity: "WindIntensity", wind_direction: "WindDirection", weather_type }`     | **未解析**         |
| `multi_player_handler`（"MultiPlayerHandler"）  | `{ role_id: "RoleID", pose_id: "PoseID", pose_playing_percent, local_pose_id, local_play_type, other_play_type }` | **未解析**         |

CameraParams 为**位置数组**（base64 → media_decrypt → JSON 数组），上游 `camera_params.rs` 布局（0 起）：

| 位段  | 内容                                                                                                                                                                                                                                                                                                                                                      | 说明                                          |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| 0–30  | V1：version(0)、portrait_mode(1)、camera_actor 位姿(2–6)、mode(7)、camera_component 位姿(8–12)、d_roll_actor(13)、focal(14)、aperture(15)、d_roll_component(16)、light_id(17)/strength(18)、vignette(19)、bloom(20–21)、brightness(22)、exposure(23)、contrast(24)、saturation(25)、vibrance(26)、highlights(27)、shadows(28)、filter_id(29)/strength(30) | 本仓 `parseCameraParams` 已按此实现，口径不动 |
| 31    | momo 标志（0=Enable 显示 / 1=Disable 携带参数）                                                                                                                                                                                                                                                                                                           | 本仓现仅读成布尔                              |
| 32–39 | momo_pose、horizontal、distance、height、rotate_momo、auto_ground_snap(0/1)、floating_effect(0/1)、pose_with_nikki(0/1)                                                                                                                                                                                                                                   | **丢弃中**                                    |
| 40–42 | nikki_pose_info：pose_id(40)、playing_percent(41，空串=无)、in_idle(42)；**40 与 42 皆为数值才成立**                                                                                                                                                                                                                                                      | **丢弃中**                                    |
| 43    | momo_pose_time（动作进度时间）                                                                                                                                                                                                                                                                                                                            | **丢弃中**                                    |

空串占位规则：momo=Enable 时 32–39 与 43 位为 `""`；数组按长度判版本（31→V1、≥40→V2、≥44→V3，多出的位忽略）。

上游显示层换算系数（`momo_camera_params_parser.rs`，仅用于**新增字段**的展示口径；V1 既有字段维持本仓现状口径不动）：`brightness=(b-0.3)/1.2`、`contrast=(c-0.55)/1.45`、`vibrance*2`、`bloom_intensity/8`、`horizontal/distance/height*400`、`rotate_momo*180`。

版本兼容边界：地点定位需游戏 2.10（2026.9.24）后的照片（有 `TrackInfo.WorldID`）；动作与进度需 2.11（2026.10.30）后（CameraParams V3）。更早照片字段缺省 → 界面显示"不支持/无数据"，不报错。

### 3.2 参考数据层（热更管线）

```
hot_update.json（上游官方站点 app_api/，含两个包的 versionId GUID + downloadLink）
  ├─ infinity_nikki：10 种语言 .bin（msgpack 语言包，string_id → 本地化名）
  └─ nuan5_database/v1.db：AES-256-GCM 加密的 protobuf
       文件布局 = salt(16B) + nonce(12B) + 密文+tag(16B)
       密钥 = HKDF-SHA256(ikm=32B 固定密钥[上游 MIT 源码], salt, info="aes-gcm-filebox", L=32)
  ↓ 解密后 protobuf 解码为 Nuan5Config：
       名称表 map<id, {string_id,...}>：light / filter / momo_pose / cloth / cloth_outfit /
         nikki_pose / nikki_pose_type（分类）/ cloth_prop / cloth_tag / world ...
       Nuan5NetworkImage：每类图片 { base_url, replace } —— CDN URL 模板
       Nuan5WorldMapTileInfo：{ url_template, min_zoom, max_zoom,
         map_width_of_max_zoom, map_height_of_max_zoom,
         original_point_x, original_point_y, px_pre_unit } —— 瓦片与坐标换算参数
```

下载主机 `file-nikki.ranaxro.com`；v3.012.02 起下载后做文件哈希校验 + 不符自动重下（哈希字段来源实采确认，见 §12）。上游栈：flutter_map（瓦片地图）+ cached_network_image + dio + msgpack_dart——**仅借鉴设计，禁止照搬 Dart 代码**。

## 5. 架构决策

1. **参考数据服务**（新文件 `src/main/services/reference-data-service.ts`，受保护路径）：启动后台延迟检查（不阻塞 8 阶段启动）+ 设置页手动刷新；manifest URL 默认上游官方地址，可被设置键 `referenceData.manifestBaseUrl` 覆盖（镜像入口，用户已定决策）；版本判定 = versionId GUID 比对（meta 落 `userData/reference-data/meta.json`）；下载/解密/索引全 fail-soft，离线用上次缓存。
2. **IPC 新域 `refdata:`**：`refdata:getStatus` / `refdata:refresh` / `refdata:lookupNames`（批量） / `refdata:getWorldMap` / `refdata:resolveImageUrl`；preload 新命名空间 `referenceData`（`src/main/preload/api/reference-data.ts`）；同步 `preload.test.ts` 键清单、`docs/IPC_CONTRACT.md` 新章节。
3. **名称解析三级降级**：`refdata:lookupNames`（在线索引）→ 打包的上游 zh-CN 名称 JSON 底座（MIT 文本数据，署名；同 cloth-names.json 先例，实采后转钉 fixture）→ 原始 ID。
4. **地图**：内嵌 MapCard（Detail 侧栏）+「独立弹窗」= BaseDialog xl 全地图视图（本仓无第二 BrowserWindow 先例，遵循 in-window 惯例，用户决策"内嵌+弹窗"由此满足）；`React.lazy` 懒加载地图组件，不进首屏包体；坐标换算公式以真实 v1.db 数据实采校准后 TDD 钉死（§12）。
5. **瓦片**：直接热链官方地址（#20 条款 6：无需 UA）；CSP `img-src` 追加实采 host；应用层不做瓦片磁盘缓存（Chromium HTTP 缓存足够，且控制缓存规模）。
6. **UA 泛化**：`cdn-user-agent.ts` 改为 host→UA 映射表（`cdn.gongeo.us → "MeowStarMap"` 原样保留；参考数据派生 host → `MeowStarMap/<version>`）；精确匹配、fail-open、测试扩展。
7. **解析扩展**（`decryption-service.ts`，受保护路径）：只增不改——V1 口径逐字段回归锁；新增字段全部可空三态。
8. **性能**：后台检查延迟触发；地图/大图懒加载；面板行有值才渲染；e2e 性能阈值（cold-start 15s 等）不得回退。

## 8. 错误处理与参数校验（贯穿）

1. 远程请求：仅 http/https；发前 host 校验，拒绝 localhost、环回、私有与保留地址（泛化 `assertSafeRemoteUrl`，`referenceData.manifestBaseUrl` 用户输入同样过闸）。
2. 超时/大小上限/重试冷却/负缓存对齐 `cloth-data-config.ts` 量级（4–5s 超时、10MB 上限、5min 冷却）。
3. 下载完整性：哈希校验（v3.012.02 对齐），不符自动重下一次，再失败降级用旧缓存并记诊断日志（不弹窗）。
4. 解密/解析 fail-soft：缺字段 → null 三态；解析异常不向 UI 抛裸错误，统一走 AppError/IpcError 与面板 error 态。
5. IPC 一律 `wrapHandler` + zod（`refdata:lookupNames` 入参批量上限、`getWorldMap` 的 worldId 正整数校验）。
6. 设置镜像 URL：zod `z.string().url()` + SSRF 闸；`referenceData.*` 进 `RENDERER_PREF_KEYS`（非安全敏感键）。

## 9. 测试计划（正常 / 异常 / 边界）

### 9.1 阶段 1（reference-data-service，fetch 注入 + 临时目录）

- 正常：manifest 有新 versionId → 下载、解密、索引建立、meta 更新；versionId 相同 → 不发起下载。
- 异常：manifest 404/超时 → 沿用缓存 + `getStatus` 报 error；哈希不符 → 自动重下一次；再失败 → 降级；SSRF（localhost/127.0.0.1/10.x/172.16.x/192.168.x/169.254.x/::1/内网域名解析）→ 拒绝且零网络调用；密文损坏 → 解密失败降级。
- 边界：meta.json 损坏 → 重建；磁盘写失败 → 内存索引本会话仍可用；并发 `refresh` → 互斥串行；空 manifest 数组 → 空态。

### 9.2 阶段 2（decryption-service）

- 正常：V2（40 位）momo Disable 全字段解析；V3（44 位）nikki_pose_info + momo_pose_time；`PhotoMode/WindIntensity/WindDirection/MultiPlayerHandler/TrackInfo` PascalCase 命中。
- 异常：字段缺省 → null/缺省行；`playing_percent` 为 `""` → null；数值为字符串数字 → 容错转换；step1 JSON 非法 → 既有 notContained/error 路径不回归。
- 边界：31 位 V1 → 输出与改动前逐字段一致；>44 位 → 忽略多余位；44 位但 40/42 位为空串 → nikkiPoseInfo=null 其余正常；`horizontal/distance/height` 为空串 → null。

### 9.3 阶段 3（组件 + i18n）

- 正常：全字段照片 → 各行渲染正确名称与进度；双人组显示对方动作。
- 异常：refdata 不可用 → 回退底座/原始 ID，无崩溃；i18n key 缺失 → `returnEmptyString:false` 回退 zh-CN。
- 边界：进度 0/1/越界值显示；字段缺省 → 行隐藏（非空行占位）。

### 9.4 阶段 4（地图）

- 正常：worldId+坐标 → 换算点落在 bounds 内；瓦片 URL 模板按 zoom 展开正确。
- 异常：worldId 无对应 tile info → 空态提示；refdata 不可用 → 禁用态。
- 边界：坐标在原点/负象限/远超地图尺寸（游戏内特殊场景）→ clamp 或"超出地图"提示；y 轴方向实采锁定。

### 9.5 阶段 5（图片）

- 正常：URL 生成（base_url+replace 各实采形态）；缓存命中 → 零网络；7 天过期 → 重取。
- 异常：404 → 负缓存不重试风暴；CDN 不可达 → 静默降级（无图标占位）。
- 边界：UA 分流三态（目标 host 改写为 `MeowStarMap/<version>`、cdn.gongeo.us 保持固定串、其他 host 零干预）。
