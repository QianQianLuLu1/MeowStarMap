### 0.4 根因裁决

**双层根因，应用内开关逻辑清白：**

1. **历史层（已消亡）**：11-21 17:15 安装修复版之前，机器上是旧构建（含 11-13 修复前的缺陷：启动期无条件按 DB 重写 + null 脏值回落 true + 旧默认 AUMID 值名），其写入的旧值名 Run 残留项导致 11-20 时代的开机自启。该构建已被覆盖安装，其 diag 历史随安装清空（diag.log 起始 11-21 17:36）。
2. **现存层（本次复发真因）**：Windows 11（build 26300）**「登录时重启应用 / 应用还原」机制**——系统在每次登录时按会话应用历史创建**临时 Run 条目**拉起应用、启动完成后立即删除（证据：0.1 时间线 + 0.2 全位置为空 + LastWriteTime 探针 + 应用零写入 + 关机前应用未运行仍被拉起）。**该机制不受应用内「开机自启动」开关控制，应用侧无法且不应对抗。**
   - 用户侧解法：关闭「设置 → 账户 → 登录选项 → 自动保存可重启的应用并在我重新登录时重启它们」（`HKCU\...\Winlogon\RestartApps`，本机该值缺省=未显式关闭）。
3. **代码侧真实盲区（本仓必须修复，对旧版残留/其它机器有效）**：
   - 启动期 `unchanged, skip write` 分支（`src/main/app/lifecycle.ts:476-477`）**从不执行残留检测清理**——历史残留项恰好使当前名回读为 false 而落入该分支，永不清理（`cleanupLegacyLoginItemNames` 唯一入口在 `syncLoginItemSetting` 成功路径，`src/main/app/login-item.ts:188-190`）。
   - `detectLegacyLoginItemNames` 只按 exe 全路径精确匹配（`login-item.ts:113`），安装目录变更即漏检（`login-item.ts:99-100`、上轮计划 §8-4 如实记录）。

**T5 裁决**：本机不存在「exe 基名也不同」的持久残留项（全盘仅 D:/AAA 修复版与 D:/e2e-keep-2.5.5 无自启功能的 2.5.5 快照）→ `LEGACY_LOGIN_ITEM_NAMES` **保持空数组**，不猜测任何值名。

## 7. 已知限制与风险（如实列全）

1. **本机的开机自启由 Windows 应用还原机制产生，应用侧代码修复不能消除它**——用户必须关闭 Windows 登录选项中的「自动保存可重启的应用」；这是 T0 取证的直接结论，不以代码修复伪造解决效果。
2. `getLoginItemSettings()` 固有盲区不变（只按当前名读；本机启动瞬间条目在应用 JS 运行前已被系统删除，新诊断行将如实记录空枚举）。
3. 基名匹配的理论误删面（第三方同名 exe）已论证为可忽略并全程留痕。
4. Windows 应用还原的内部实现（创建/删除临时条目的确切组件）无法从本环境进一步取证，属 OS 内部行为，已按可观测证据链如实记录。

### 8.2 真机验收清单（用户本机执行，非自动化）

1. **关闭 Windows「登录时重启应用」**：设置 → 账户 → 登录选项 → 关闭「自动保存可重启的应用并在我重新登录时重启它们」。
2. **重启电脑**：期望喵星图不再自启。复核命令（开机后）：
   `powershell -Command "Get-WinEvent -FilterHashtable @{LogName='Microsoft-Windows-Shell-Core/Operational'; Id=9707; StartTime=(Get-Date).Date} | Where-Object { $_.Message -match '喵' }"`
   ——期望无输出（本次取证的 9707 拉起记录不再出现）。
3. **应用内开关回归**：设置 → 启动行为 → 开机自启动 开→关；`reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Run"` 应出现后消失 `com.qianlu.meow-star-map`。
4. **diag 留痕核对**：安装目录 `Diagnostics\diag.log` 每次启动应出现 `launchItems enumerated:` 行（内容为空同样有价值——证明系统在应用运行前已清理其临时条目）；若有残留项被清理，应出现 `legacy cleanup: name=…`。
5. **应用还原机制说明**：若关闭 Windows 设置后重启仍自启，重复步骤 2 的复核命令并回报输出——那将指示另有机制，需再取证。
