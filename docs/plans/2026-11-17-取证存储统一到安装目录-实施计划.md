# 实施计划：问题取证存储统一到安装目录 Diagnostics 并整合「导出诊断包」

> 日期：2026-11-17 · 仓库根：`D:\项目\软件\MeowStarMap\MeowStarMap\MeowStarMap`
> 上游：`docs/plans/2026-11-15-双击启动异常分析与残留缺陷修复-实施计划.md` §4 取证清单（本轮把该清单的存储统一收口）

## Context（背景与目标）

上一轮交付的「问题电脑取证清单」对应的文件目前分散在三处：`Documents/喵星图/Diagnostics`（diag.log / startup-errors.log / chromium-debug.log / .dmp）、`userData`（heartbeat.json / last-exit.json / gpu-fallback.json / gpu-pref.json / boot-ok.marker / second-instance-ack.json / logs/ 电子日志）、用户自定义目录（log/crash 可自选）。本轮目标：

1. **统一归集**：打包态全部取证文件落 `<安装目录>\Diagnostics`，无分散。
2. **复用整合**：与「导出诊断包」（三入口共用 `log:exportZip` → `log-service.ts exportLogsAsZip`）深度整合，导出补齐 heartbeat/last-exit/boot-ok.marker。
3. **双机制**：窗口正常 → 导出诊断包（主）；窗口拉不起 → 安装目录 Diagnostics 直接可查（应急，写入点统一后天然达成）。

**已确认决策**：① 安装目录不可写（自定义装到 Program Files 等）→ 回落现有 `getUserFacingDiagDir()` 候选链（Documents → homedir → tmpdir），导出包 manifest 登记 `source: 'fallback'`；② 取证强制统一——设置页 log/crash 自定义目录入口移除（backup/thumbnail 保留）；③ 升级首启一次性迁移旧取证文件（原件保留、幂等）。**已知接受的约束**：NSIS 卸载会清空安装目录（取证随卸载丢失，旧位置原件 + 导出包兜底）；per-machine 安装多用户共享会互相覆盖心跳等瞬态文件。

**NSIS 事实**：per-user 安装（默认 `%LOCALAPPDATA%\Programs`，可写），`allowToChangeInstallationDirectory: true` 允许装到受保护目录（`asInvoker` 写入被拒 → 走回落）。

## 一、新模块：`src/main/utils/forensics-dir.ts`（取证根目录单一真相源）

沿用 `user-diag-path.ts` 的「零 electron 依赖叶子模块 + provider 注入」模式：

- 常量：`FORENSICS_DIRNAME = 'Diagnostics'`、`FORENSICS_LOGS_SUBDIR = 'logs'`；复用 `user-diag-path` 的 `CHROMIUM_LOG_BASENAME` 等（import 不复制）。
- `setForensicsEnvProvider(fn)`：由 `index.ts` 模块加载早期注册 `() => ({ isPackaged: app.isPackaged, exePath: app.getPath('exe') })`（均可 ready 前调用）；注册/清空使缓存失效（测试重置缝）。
- `getForensicsRoot(): string`（模块级单次缓存）：
  1. provider 缺失 / 非打包态 → 返回 `getUserFacingDiagDir()`（**dev 不碰 node_modules**，行为与现状对齐）；
  2. 打包态 → `path.join(path.dirname(exePath), 'Diagnostics')`，用 `path-safety.ts` 的 `ensureWritableDir`（L37-45）探测可写 → 成功采用；
  3. 探测失败 → 回落 `getUserFacingDiagDir()`。
- `getForensicsRootSource(): 'install' | 'fallback'`；`getForensicsFilePath(name)`（入参校验：非空 string、无 `/` `\` `..`，违例 throw）；`getForensicsLogsDir()`。

落盘布局（打包态）：

```
<安装目录>\Diagnostics\
  diag.log  startup-errors.log  chromium-debug.log(.old)
  heartbeat.json  last-exit.json  boot-ok.marker  second-instance-ack.json
  gpu-fallback.json  gpu-pref.json
  *.dmp（crashDumps 平铺指向根，crash-service 扫描口径零改动）
  logs\（main-YYYY-MM-DD.log、faults-*.jsonl）
```

## 九、风险与权衡

1. Program Files 回落链兜底 + 导出包 `source: fallback` 可感知；不申请提权（维持安装器语义）。
