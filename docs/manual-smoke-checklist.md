# 人工冒烟清单（发布前逐项勾选）

> 来源：`docs/archive/plans/e2e-smoke-playwright.md` §6（该目录被 `.gitignore` 排除、不入仓，仅本机留存，git 历史可查）。
> 自动化冒烟（`npm run e2e:smoke`）覆盖启动/白屏/preload/IPC/SQLite 探针；
> 本清单覆盖**依赖真实游戏图片/视频样本**的深度功能，二者互补，发布前缺一不可。
>
> 适用时机：每次发布前，对 `release/win-unpacked/*.exe`（或安装后的 exe）在
> **全新环境**（或全新 userData）执行。

```
发布版本：__________    测试机：__________    日期：__________

【启动】
[ ] 双击 exe 后 10s 内窗口出现，无白屏、无错误弹窗
[ ] 首次启动自动建库完成，首页/引导页正常渲染
[ ] 主题显示正常（默认简约 / 柔粉轻奢切换一次）

【窗口与外壳】（2026-10-30 新增，对应 2.5.6-beta 的无边框拖拽修复）
[ ] 拖窗口标题栏与顶部空白热区可移动窗口；按钮、卡片、滚动列表区域内拖动**不带**窗口移动
[ ] 双击顶部热区可最大化/还原；拖拽到屏幕边缘的贴边行为正常（此项无法自动化，`app-drag-region.test.ts` 只钉 CSS 声明存在，不验手感）

【扫描】
[ ] 选择包含游戏照片的目录，扫描进度条正常推进并可取消
[ ] 扫描完成后照片入库，数量与目录实际一致
[ ] 中断后再启动，出现"上次扫描未完成"提示（半可见性）

【缩略图】
[ ] 图库缩略图正常生成显示（低清→高清档位）
[ ] 大量图片滚动时无明显卡顿/黑图

【解密 / 游戏数据】
[ ] 游戏参数文件（.data 类）能被识别并解码预览
[ ] 染色分享码 / 家园建造分享码解码各验证一条

【搜索】
[ ] 文件名关键字搜索有结果返回
[ ] 分类 / 套装 / 场景筛选可用

【插件】
[ ] 插件页能列出示例插件（plugins-samples 安装后）
[ ] 启停插件一次，界面扩展点生效/消失

【编辑与导出】
[ ] 编辑器打开一张图，套一个滤镜并保存（备份生成）
[ ] 水印应用一次；导出到目标目录成功

【同步】（2026-10-30 新增，对应 2.5.6-beta 的路径裁剪定版）
[ ] 设置页开启同步服务后，手机扫码可完成配对；同步图库能加载出缩略图与元数据
[ ] 开发者工具 Network/IPC 响应里**不含本机绝对路径**（无 `D:\` / `C:\Users\` 形态的 `sourcePath`/`sourceFolder`）——委托层裁键是本版本的交付判据，肉眼复核一次
[ ] 停止同步服务后配对码不可得、设备列表按前置条件失败（不留可用的旧会话）

【托盘】（2026-11-14 新增，对应 2.5.7 的 windows-shell 对齐；打包模式执行）
[ ] 设置 → 同步服务 → Windows 外壳能力开启「托盘常驻」并**重启应用**，任务栏通知区出现应用图标（运行期切换需重启生效）
[ ] 双击托盘图标或菜单「Show MeowStarMap」可显示并聚焦主窗口
[ ] 托盘菜单「Quit MeowStarMap」退出后，任务管理器确认无残留进程
[ ] 关闭「托盘常驻」并重启，托盘图标消失
失败判定：图标不出现 / 菜单无响应 / 退出后进程残留

【开机自启】（2026-11-14 新增，对应 2.5.7；仅打包模式执行——dev 模式保存的预期是 toast「开发模式不修改系统启动项，设置已保存」且 OS 无变化）
[ ] 设置 → 通用 → 启动开启「开机自启动」保存成功，任务管理器「启动应用」页出现本应用（或注册表 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 含 com.qianlu.meow-star-map）
[ ] 注销并重新登录 Windows，应用随登录自动启动且主窗口正常出现
[ ] 关闭「开机自启动」保存成功后，上述启动项消失
失败判定：保存报错 / 开关回滚 / 启动项未写入或未移除

【自动更新】（2026-11-14 新增，对应 2.5.7）
[ ] 场景 A（dev feed）：`MEOW_DEV_UPDATE_FEED=1` 且 `npx tsx scripts/serve-dev-update-feed.ts --version 9.9.9 --port 8123` 在跑，dev 启动后 设置 → 关于 → 检查更新 发现 9.9.9，出现居中决策模态；下载时为右下角非阻塞进度卡
[ ] 场景 B（打包态）：打包 exe 的 设置 → 关于 → 检查更新 返回「暂无更新」，不崩溃、无误导性错误弹窗（2.5.7 尚未发布 Release，not-available 为预期）
失败判定：dev feed 无反应 / IPC 错误未兜底；打包态崩溃或误报可更新

【数据完整性】
[ ] 回收站软删除→恢复 一次
[ ] 数据库备份→恢复 一次
[ ] 重启应用，以上数据仍在

【异常兜底】
[ ] 打开一个不含任何图片的空目录扫描，无崩溃
[ ] 任务管理器确认退出后无残留进程
```
