# 设计令牌（Design Tokens）

本项目所有视觉参数（颜色、阴影、圆角、间距、过渡、毛玻璃模糊半径）都以 CSS 变量形式
集中声明在 `src/renderer/styles/globals.css` 的 `:root` 中，组件只引用变量、不硬编码具体值。
**本页色板全部使用 `var(--token)` 实时渲染** —— 切换工具栏「主题」下拉，色板会即时反映主题差异。

主题体系：

- 默认主题：变量直接在 `:root` 声明（`styles/themes/index.ts` 中 `className` 为空）
- 「柔粉轻奢」主题：`styles/themes/soft-pink-luxury.css` 通过 `.soft-pink-luxury` 类覆盖同名变量
- 切换机制：`stores/themeStore.ts` 的 `applyThemeClass` 在 `<html>` 上附加 / 移除主题类

## 间距令牌（P1-U8 spacing token 体系）

紧凑模式（`html.compact-mode`）通过整体替换这组 token 生效，组件不感知模式差异。

| 令牌                    | 默认 | 紧凑模式 | 典型用途             |
| ----------------------- | ---- | -------- | -------------------- |
| `--space-card-padding`  | 20px | 12px     | `.glass-card` 内边距 |
| `--space-card-gap`      | 16px | 10px     | 卡片内子元素纵向间距 |
| `--space-nav-padding-y` | 10px | 6px      | 导航项纵向内边距     |
| `--space-nav-padding-x` | 16px | 10px     | 导航项横向内边距     |
| `--space-nav-gap`       | 12px | 8px      | 导航项图标与文字间距 |
| `--space-toolbar-gap`   | 12px | 8px      | 工具栏元素间距       |

## 毛玻璃令牌

`--backdrop-blur` / `--backdrop-blur-sm` 是派生变量（`blur(var(--glass-blur))`），
`prefers-reduced-motion` / `html.reduce-motion` 下降级时通过覆盖 `--glass-blur*` 固定模糊半径。

| 令牌              | 默认 | 柔粉轻奢 | 用途                    |
| ----------------- | ---- | -------- | ----------------------- |
| `--glass-blur`    | 12px | 12px     | 主毛玻璃（面板 / 弹窗） |
| `--glass-blur-sm` | 8px  | 10px     | 轻量毛玻璃（标题栏等）  |

## 双主题差异一览

| 分组          | 默认主题（浅色简约） | 柔粉轻奢 `soft-pink-luxury`                |
| ------------- | -------------------- | ------------------------------------------ |
| 背景          | `#f5f5f5` 中性灰白   | `#fdf9fb` 奶白 + 柔雾渐变                  |
| 强调色        | `#0078d4` Windows 蓝 | `#e2a4bc` 低饱和柔粉                       |
| 分隔线 / 悬停 | 中性黑低透明度       | 柔粉染色（`rgba(226,164,188,…)`）          |
| 阴影          | 中性黑               | 粉色染色阴影                               |
| 附加变量      | —                    | `--glow-pink` / `--glow-pink-sm` 柔光      |
| 组件级覆盖    | —                    | 按钮渐变、搜索框光晕、进度条渐变等局部样式 |

约束（来自代码评审沉淀，修改令牌时务必遵守）：

1. 组件禁止硬编码颜色 / 间距 / 圆角，一律引用变量或公共组件类（`.glass-card`、`.btn-primary` 等）；
2. 主题文件只覆盖变量与必要的组件级差异，不重复声明完整规则与过渡时长；
3. 毛玻璃必须 `backdrop-filter` 与 `-webkit-backdrop-filter` 双写；
4. 新增主题需在 `styles/themes/index.ts` 注册，并在 `globals.css` 顶部 `@import` 同名 CSS。
